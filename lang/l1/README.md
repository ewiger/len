# L1

L1 is the level 1 layer of a meta-language called `len` for expressing design and specification of domain knowledge in programming, mathematics, etc. This is done by means of relational logic with primitives like `type` and `rel`. 

## Core

Core L1 consists of two main parts:

- **core.syntax** = meta-language tokens and open-ended expression carrier

- **core.math.logic.logic** = human-facing logical aliases built on top of L1 core connectives

Then it is extended by various domain-specific libraries, e.g. `core.math.set` for set theory and `core.math.nat` for natural numbers.
