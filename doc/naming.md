# Naming Conventions
This document describes the naming conventions used in this project. The goal is to maintain consistency and clarity across all documentation and code.

## Axioms, Definitions and Claims

Not every spec is an axiom. A spec is just a declared statement; its role is determined by its label: axiom, definition, postulate, property, theorem, or schema.

Use this convention for mathematical statements:

- **axiom** only for the canonical basis of the theory
- **postulate** for local primitive assumptions
- **definition** for introduced notions
- **theorem** for derivable statements
- **claim** for statements that are not yet proven but are believed to be true
- **lemma** for auxiliary statements that are used in the proof of theorems
- **corollary** for statements that follow directly from a theorem
- **conjecture** for statements that are believed to be true but have not yet been proven
- **remark** for observations that are not part of the main argument but are worth noting
- **example** for illustrative cases that demonstrate the application of a concept or theorem
