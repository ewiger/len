# len example corpus

This folder contains ten mini-projects for testing the design space of `len`.

Each example is expressed in three layers:

- `.l0` high-level controlled natural language
- `.l1` sugared len for human authors
- `.l2` canonical predicate-oriented len closer to the semantic core

The examples are intentionally diverse so we can compare how well the language handles:

- mathematical recurrence and theorem obligations
- cloud infrastructure constraints
- small DSL design
- testing and validation contracts
- operational policies and workflow rules
